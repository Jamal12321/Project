1. Актуальность темы
Футбол — самый популярный вид спорта в мире. Миллионы болельщиков ежедневно обсуждают предстоящие матчи, пытаются предсказать исход. Однако большинство прогнозов основываются на субъективном мнении, а не на объективных данных. Существуют платные сервисы, но они недоступны широкой аудитории. Поэтому создание бесплатного, простого и наглядного инструмента, который автоматически анализирует статистику и даёт вероятностный прогноз, является актуальной задачей. Кроме того, работа позволяет применить навыки программирования (Python, Flask, API) в реальной практической задаче.

11. Проблема 1: Ограничения бесплатного API Football Data. Бесплатный тариф разрешает не более 10 запросов в минуту. Для сбора данных о 100+ командах потребовалось бы несколько часов, а при случайном превышении лимита API блокирует ключ на час. Решение: разработан отдельный скрипт update_data.py, который делает запросы с принудительной задержкой 6 секунд, а все полученные данные сохраняет в локальные JSON-файлы.
Файл запускается отдельно, раз в день и никак не влияет на работу сайта.
Проблема 2: Создание более точного  алгоритма предсказаний, была решена в течении недели раздумий над ней, придя к тому, что лимит запросов у меня ограничен, а для точных предсказаний нужно намного больше данных, было принято решение сделать алгоритм простым, используя статистику команд, за последние 5 матчей, тем самым решив сразу 2 проблемы, алгоритм стал работать быстрее, а предсказания стали более точными
Проблема 3: Развертывание сайта на бесплатном хостинге Railway.com не видел многие файлы, решена была изменением структуры файлов в корневой папке на Github

В. Инструкция по запуску сайта на локальном сервере
Установить Python версии 3.10 или выше.
Склонировать репозиторий проекта.
Установить зависимости из файла requirements.txt: pip install -r requirements.txt.
Получить API-ключ на сайте football-data.org и добавить его в переменную окружения PARSING_KEY.
Один раз запустить скрипт обновления данных: python update_data.py (требуется интернет, процесс может занять до 10 минут).
Запустить веб-приложение: python app.py.
Перейти в браузере по адресу http://127.0.0.1:5000.
